# Portfolio

My personal portfolio website showcasing my projects, skills, and TryHackMe achievements.

## 🌟 Features

- Modern, responsive design
- Dark/Light theme toggle
- Real-time TryHackMe badge integration
- Project showcase
- Skills and certifications

## 🚀 Live Demo

Visit: https://SlashEr-11.github.io/portfolio/modern.html

## 📊 TryHackMe Stats

This portfolio includes a live TryHackMe badge and a link to the profile.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📝 How to Update

1. Make your portfolio changes.
2. Commit and push them:
   ```bash
   git add .
   git commit -m "Update TryHackMe stats"
   git push origin main
   ```
3. Changes will automatically deploy to GitHub Pages
