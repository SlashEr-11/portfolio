# Portfolio

My personal portfolio website showcasing my projects, skills, and TryHackMe achievements.

## 🌟 Features

- Modern, responsive design
- Dark/Light theme toggle
- Real-time TryHackMe badge integration
- GitHub-style contribution chart for TryHackMe activity
- Project showcase
- Skills and certifications

## 🚀 Live Demo

Visit: https://SlashEr-11.github.io/portfolio/modern.html

## 📊 TryHackMe Stats

This portfolio features real-time integration with TryHackMe:
- Live badge showing current rank
- Activity contribution chart
- Detailed statistics

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📝 How to Update

1. Update your TryHackMe stats in `tryhackme-data.json`
2. Commit and push changes:
   ```bash
   git add .
   git commit -m "Update TryHackMe stats"
   git push origin main
   ```
3. Changes will automatically deploy to GitHub Pages
