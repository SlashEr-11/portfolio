## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/SlashEr-11/<repository-name>.git
   ```

2. Open the project directory:

   ```bash
   cd <repository-name>
   ```

3. Open `sourabh_portfolio.html` in a web browser.

For a smoother local-development experience, you can use the **Live Server** extension in VS Code and open `sourabh_portfolio.html` with it.

## Deploy with GitHub Pages

1. Push this project to a GitHub repository.
2. On GitHub, open **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your deployment branch (usually `main`) and the **/(root)** folder.
5. Save the settings and wait for GitHub Pages to publish the site.

> GitHub Pages looks for an `index.html` file by default. Rename `sourabh_portfolio.html` to `index.html` before deploying, or make a copy named `index.html`.
